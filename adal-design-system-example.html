# Ada Design System Example — Landing Page Reference

> A saturated pink stage for an automation-first agent. The dark interface is compact, functional, and intentionally quiet.

**Theme:** black / pink / high-contrast product editorial

Ada Design System Example pairs a vivid pink canvas with near-black interface surfaces. Space Grotesk carries the display and UI roles; mono text is reserved for commands and utility labels. Navigation and controls stay compact so the product promise remains dominant.

## Tokens — Colors

The visual palette is shown in the left human-reference pane. Use these names in implementation: --adal-pink: #FF5898, --adal-ink: #16070D, --adal-panel: #21131A, --adal-white: #FFFFFF, and --adal-pink-soft: #FFB2CF.

## Spacing & Shape

  • Base unitUse a 4px rhythm. Let larger gaps scale in clear multiples rather than inventing one-off spacing.
  • Page frameKeep content wide but bounded: the hero breathes, while commands and paragraphs maintain readable line lengths.
  • Surface radiusUse 12px for command surfaces and 999px only for navigation or button pills.
  • DepthUse a subtle border and one soft warm shadow beneath dark floating surfaces. Do not stack shadows.

## Layout Rules

  • HeroOne oversized two-line promise, short technical explanation, then the install command.
  • InterfaceFloat dark, rounded controls on the pink canvas. Keep labels small and readable.
  • Focal objectUse one expressive visual—such as the page-peel mascot—not several competing decorations.
  • ChaptersEach product section gets one outcome, one proof point, and one visual demonstration.
  • MobilePreserve pink canvas and dark command surface; collapse navigation and stack content without horizontal overflow.

## Guidelines

  • DoUse pink as the large product canvas and near-black as the functional control layer.
  • DoKeep Space Grotesk tight and oversized for product promises; reserve mono text for commands, tabs, and utility labels.
  • DoLet one expressive visual carry personality while the rest of the interface stays quiet.
  • Don’tTurn every section pink, add competing gradients, or introduce unrelated chromatic accents.
  • Don’tUse several primary CTAs in one viewport or decorate the layout until the product message is harder to read.

## Component Kit

  • HeaderMascot icon, centered dark nav pill, white conversion action.
  • CommandDark terminal surface with mono command text and an explicit copy button.
  • UnderlineIrregular dark brush mark beneath the hero’s emphasis phrase.
  • ProofLogos, workflow steps, and product screenshots remain secondary to the promise.

The starting point

Two ways to build a landing page.

Choose the input. AdaL handles the research, build, and visual checks.

01 / CLONE

Start with a page you like.

Use an existing landing page, Framer site, or free preview. Reverse-engineer it, then make it yours.

02 / AVAILABLE PROMPT

Start with a prompt you can copy.

Use an AI-native prompt from a library such as MotionSites, then adapt it for your product.

02 / Available prompt

Copy the prompt.
Paste it into AdaL.

AI-native design libraries package their taste as prompts. The prompt is the brief: copy it, replace the product details, and ask AdaL to build and verify it.

> Build this landing page prompt for MY_PRODUCT. Keep the layout and motion direction, but rewrite the copy, colors, and visual assets for my brand. Build responsive desktop and mobile versions, then open the result and fix visual problems.

Without paying: use a library’s free preview as a reference for the clone method, or copy a free prompt/component from 21st.dev, Magic UI, or an available MotionSites prompt.

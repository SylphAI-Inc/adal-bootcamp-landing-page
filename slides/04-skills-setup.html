Skills

Give AdaL
reusable knowledge.

Skills are small instruction packs that help AdaL do a kind of work consistently.

Browse skills on atskills.one ↗
> @skills:gh:SylphAI-Inc/skills/skills/clone-anywebsite

Project skills

Keep your skills
in .atskills.

A project skill lives with the project, so AdaL can use the same instructions every time.

> .atskills/
  design-review/
    SKILL.md

Put the reusable instructions in SKILL.md. Keep project-specific skills close to the project.

Find a skill

Ask AdaL
to find it.

The skill tool can search the skills catalogue and read the skill that matches your task. You do not need to know the path first.

> Find a skill for reviewing a landing page.

AdaL searches, reads the relevant instructions, and uses them for the task.

Use a skill

Type @
to add one.

Use @ when you already know the skill you want. Nothing installs or stays in the prompt unless you choose it.

> @skills:gh:owner/repo/path

Read it for this task. Add :save to keep a project copy, or :install to make it auto-trigger.

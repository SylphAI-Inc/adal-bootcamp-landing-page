Three commands

The controls
you need today.

/init

Give AdaL project context before the build starts.

/model

Choose the right model for research, design, or implementation.

/capabilities

See browser-use and video when the work needs them.

Shift + Tab

Choose the level
of control.

Cycle modes with Shift + Tab. The current mode stays visible in AdaL’s status bar.

STRICT

Ask first.

AdaL asks before edits and commands. Use this while learning or reviewing a sensitive project.

ACCEPT EDITS

Let edits flow.

AdaL applies edits; commands still need approval.

YOLO

Run the loop.

AdaL can plan, build, test, and iterate without stopping for each step.

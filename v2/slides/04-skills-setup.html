THE GOLDEN RULE

Trust screenshots first.

Use the live DOM to extract exact facts when a visual effect is complex. Do not blindly copy builder-generated divs or guess the animation math.

The live prompt

Give AdaL
a target.

After loading the skill, give it a focused scope. Start with one hero; use the full page only after the first reference is understood.

> Clone the hero section of TARGET_URL. Capture 1440×1400, 1920×1200, and 390×844 screenshots. Extract the layout, fonts, colors, assets, and animation timing. Build it in my project, then compare the target and build at every viewport and fix the visible differences.
WHAT TO BRING

One URL.
One product.

Pick a page whose structure or motion you want to study. Use your own product name, copy, and visual identity in the final build.

Before you call it done

Check the result.
Then ship it.

LAYOUT

Compare every viewport.

Check the target and the build at 1440, 1920, and 390 px. Do not approve only the first desktop screenshot.

TYPE + COLOR

Use extracted values.

Check font family, size, tracking, line height, colors, borders, and shadows against the reference.

MOTION

Record what moves.

Use video or a GIF for entrance, hover, and scroll effects. A still image cannot prove the timing is right.

OWNERSHIP

Make it yours.

Keep the learned structure and design direction. Replace source branding, copy, and proprietary assets with your own.
